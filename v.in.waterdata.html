DESCRIPTION

v.in.nwis imports USGS National Water Information System (NWIS) stream gauge data into GRASS GIS. It can retrieve gauge locations as vector points, upstream drainage basin boundaries as vector polygons (via the USGS Network Linked Data Index, NLDI), and daily discharge time series stored as a linked SQLite table.

Gauges can be specified by NWIS site ID or, if none are given, all stream gauges with daily-value records within the current GRASS computational region are retrieved.

NOTES

Required Python packages

v.in.nwis requires the following Python packages, which are not part of the standard GRASS installation:
  • dataretrieval — USGS NWIS data access
  • geopandas — geospatial DataFrames
  • shapely — geometry objects (usually installed with geopandas)
Install with pip: 
pip install dataretrieval geopandas
Or with conda: 
conda install -c conda-forge dataretrieval geopandas

Gauge locations

Gauge locations are imported as a vector point map. The attribute table contains the NWIS site metadata including site number, station name, latitude, longitude, and drainage area (where available).

Upstream drainage basins

With the -b flag, upstream drainage basin polygons are fetched from the USGS Network Linked Data Index (NLDI) and imported as a separate vector polygon map. The basins option must also be specified. Basin polygons are keyed to gauge locations by the site_no attribute.

NLDI basins are pre-computed and delivered as polygons in EPSG:4326. For gauges outside the NHDPlus network (e.g. non-US locations) use r.watershed and v.stream.inbasin instead.

Time series

With the -t flag, daily values for the chosen parameter code are fetched and stored in the mapset SQLite database as a table named <output>_timeseries, with columns:
  • site_no — NWIS site identifier (links to the gauge point map)
  • datetime — date as a string (YYYY-MM-DD HH:MM:SS+00:00)
  • value — measured value in the parameter's native units
  • flag — NWIS quality code (A=approved, P=provisional, e=estimated)
The table can be queried with: 
db.select sql="SELECT * FROM gauges_timeseries WHERE site_no='05331000' LIMIT 10"

Coordinate reference system

NWIS gauge locations and NLDI basins are delivered in EPSG:4326 (WGS84 geographic). v.in.ogr reprojects them to the current GRASS location's CRS on import.

EXAMPLES

Import all stream gauges with daily records within the current region: 
v.in.nwis output=gauges
Import specific gauges by site ID: 
v.in.nwis output=gauges sites=05331000,05288500
Import gauges, upstream basins, and 10 years of daily discharge: 
v.in.nwis output=gauges basins=basins sites=05331000 \
    start_date=2010-01-01 end_date=2019-12-31 -bt
Import only basins and time series (no additional region query): 
v.in.nwis output=gauges basins=basins sites=05331000,05330900 \
    parameter_cd=00065 start_date=2020-01-01 end_date=2023-12-31 -bt

EXTENDED EXAMPLE: Mississippi River at St. Paul

USGS gauge 05331000 (Mississippi River at St. Paul, MN) has a continuous daily discharge record from 1892 to the present (48,000+ days) and a drainage area of 36,800 mi² (95,300 km²) covering much of the upper Midwest. This example demonstrates the complete workflow: importing the gauge, its upstream basin, and the full historical discharge record, then querying the results. The full script is also available as example/mississippi_stpaul.sh.

1. Set the computational region and import data

g.region n=45.1 s=44.8 e=-92.9 w=-93.3 res=0:00:30

v.in.nwis output=mississippi_stpaul \
          basins=mississippi_stpaul_basin \
          sites=05331000 \
          parameter_cd=00060 \
          start_date=1892-03-01 \
          end_date=2026-06-06 \
          -bt
This creates:
  • mississippi_stpaul — vector point map of the gauge location
  • mississippi_stpaul_basin — vector polygon of the upstream drainage basin
  • mississippi_stpaul_timeseries — SQLite table of 48,254 daily discharge values

2. Gauge metadata and NWIS-reported drainage area

The drain_area_va column (drainage area in mi²) is retrieved directly from NWIS site metadata: 
db.select sql="SELECT site_no, station_nm, dec_lat_va, dec_long_va, drain_area_va \
               FROM mississippi_stpaul"

site_no |station_nm                        |dec_lat_va |dec_long_va |drain_area_va
05331000|MISSISSIPPI RIVER AT ST. PAUL, MN |44.9444444 |-93.0881111 |36800.0

3. Basin area computed from the imported polygon

v.to.db computes the area of the basin polygon independently as a cross-check against the NWIS-reported value: 
v.to.db map=mississippi_stpaul_basin option=area columns=area_sq_km units=kilometers

db.select sql="SELECT site_no, \
                      ROUND(area_sq_km, 0)        AS area_km2, \
                      ROUND(area_sq_km / 2.590, 0) AS area_mi2 \
               FROM mississippi_stpaul_basin"

site_no |area_km2|area_mi2
05331000|  95343 |   36812

4. Time series queries

Record extent and basic statistics: 
db.select sql="SELECT COUNT(*)             AS n_days, \
                      MIN(datetime)        AS first_date, \
                      MAX(datetime)        AS last_date, \
                      ROUND(MIN(value), 0) AS min_cfs, \
                      ROUND(AVG(value), 0) AS mean_cfs, \
                      ROUND(MAX(value), 0) AS max_cfs \
               FROM mississippi_stpaul_timeseries \
               WHERE value IS NOT NULL"

n_days|first_date               |last_date                |min_cfs|mean_cfs|max_cfs

               WHERE value IS NOT NULL \
               ORDER BY value DESC \
