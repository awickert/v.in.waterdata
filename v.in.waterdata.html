DESCRIPTION

v.in.waterdata imports USGS stream gauge data from the USGS Water Data for the Nation API into GRASS GIS. It can retrieve gauge locations as vector points, upstream drainage basin boundaries as vector polygons (via the USGS Network Linked Data Index, NLDI), daily discharge time series, shift-adjusted rating curves, and channel geometry from field measurements — all stored in the current mapset.

Gauges can be specified by USGS site ID or, if none are given, all stream gauges within the current GRASS computational region are retrieved.

NOTES

Required Python packages

v.in.waterdata requires the following Python packages, which are not part of the standard GRASS installation:
  • dataretrieval — USGS Water Data API access
  • geopandas — geospatial DataFrames
  • shapely — geometry objects (usually installed with geopandas)
Install with pip: 
pip install dataretrieval geopandas
Or with conda: 
conda install -c conda-forge dataretrieval geopandas

Gauge locations

Gauge locations are imported as a vector point map. The attribute table contains USGS monitoring location metadata including site_no (bare numeric ID), monitoring_location_name (station name), drainage_area (reported drainage area in mi²), and many additional fields (state, county, hydrologic unit, altitude, etc.).

Upstream drainage basins

With the -b flag, upstream drainage basin polygons are fetched from the USGS Network Linked Data Index (NLDI) and imported as a separate vector polygon map. The basins option must also be specified. Basin polygons are keyed to gauge locations by the site_no attribute.

NLDI basins are pre-computed and delivered as polygons in EPSG:4326. For gauges outside the NHDPlus network (e.g. non-US locations) use r.watershed and v.stream.inbasin instead.

Time series

With the -t flag, daily values for the chosen parameter code are fetched and stored in the mapset SQLite database as a table named <output>_timeseries, with columns:
  • site_no — USGS site identifier (links to the gauge point map)
  • datetime — date as a string (YYYY-MM-DD HH:MM:SS)
  • value — measured value in the parameter's native units
  • unit_of_measure — unit string (e.g. ft^3/s)
  • approval_status — Approved or Provisional
  • qualifier — optional qualifier such as ESTIMATED (NULL if none)
The table can be queried with: 
db.select sql="SELECT * FROM gauges_timeseries WHERE site_no='05331000' LIMIT 10"

Rating curves

With the -r flag, the current shift-adjusted rating curve is fetched for each site and stored as a table named <output>_ratings, with columns:
  • site_no — USGS site identifier
  • stage_ft — gage height (ft)
  • shift_ft — current applied shift (ft)
  • discharge_cfs — shift-adjusted discharge (ft³/s)
The rating curve is the dense expanded lookup table used operationally by USGS to convert stage readings to discharge values.

Channel geometry

With the -c flag, channel geometry summaries from each field measurement visit are stored as a table named <output>_channel, with columns:
  • site_no — USGS site identifier
  • datetime — date and time of field visit
  • channel_width — measured channel width (ft)
  • channel_area — measured cross-sectional area (ft²)
  • channel_velocity — mean cross-sectional velocity (ft/s)
  • channel_flow — measured discharge (ft³/s)
  • channel_stability — bed stability assessment
  • channel_material — dominant bed material
  • measurement_type — measurement method (e.g. BridgeCrane, wading)
Channel geometry records document morphological change over time and provide the field measurements used to construct and update rating curves.

Coordinate reference system

USGS gauge locations and NLDI basins are delivered in EPSG:4326 (WGS84 geographic). v.in.ogr reprojects them to the current GRASS location's CRS on import.

EXAMPLES

Import all stream gauges within the current region: 
v.in.waterdata output=gauges
Import specific gauges by site ID: 
v.in.waterdata output=gauges sites=05331000,05288500
Import gauges, upstream basins, and 10 years of daily discharge: 
v.in.waterdata output=gauges basins=basins sites=05331000 \
    start_date=2010-01-01 end_date=2019-12-31 -bt
Import gauge with rating curve and channel geometry: 
v.in.waterdata output=gauges sites=05331000 -rc
Import everything for a single gauge: 
v.in.waterdata output=gauges basins=basins sites=05331000 \
    parameter_cd=00060 start_date=2020-01-01 end_date=2023-12-31 -btrc

EXTENDED EXAMPLE: Mississippi River at St. Paul

USGS gauge 05331000 (Mississippi River at St. Paul, MN) has a continuous daily discharge record from 1892 to the present (48,000+ days) and a drainage area of 36,800 mi² (95,300 km²) covering much of the upper Midwest. This example demonstrates the complete workflow: gauge location, upstream basin, full historical discharge record, shift-adjusted rating curve, and channel geometry from field visits. The full script is also available as example/mississippi_stpaul.sh.

1. Set the computational region and import data

g.region n=45.1 s=44.8 e=-92.9 w=-93.3 res=0:00:30

v.in.waterdata output=mississippi_stpaul \
               basins=mississippi_stpaul_basin \
               sites=05331000 \
               parameter_cd=00060 \
               start_date=1892-03-01 \
               end_date=2026-06-06 \
               -btrc
This creates:
  • mississippi_stpaul — vector point map of the gauge location
  • mississippi_stpaul_basin — vector polygon of the upstream drainage basin
  • mississippi_stpaul_timeseries — SQLite table of 48,254 daily discharge values
  • mississippi_stpaul_ratings — SQLite table of the shift-adjusted rating curve
  • mississippi_stpaul_channel — SQLite table of channel geometry from field visits

2. Gauge metadata and reported drainage area

db.select sql="SELECT site_no, monitoring_location_name, drainage_area \
               FROM mississippi_stpaul"

site_no |monitoring_location_name          |drainage_area
05331000|MISSISSIPPI RIVER AT ST. PAUL, MN |36800.0

3. Basin area computed from the imported polygon

v.to.db map=mississippi_stpaul_basin option=area columns=area_sq_km units=kilometers

db.select sql="SELECT site_no, \
                      ROUND(area_sq_km, 0)         AS area_km2, \
                      ROUND(area_sq_km / 2.590, 0) AS area_mi2 \
               FROM mississippi_stpaul_basin"

site_no |area_km2|area_mi2
05331000|  95343 |   36812

4. Time series queries

Record extent and basic statistics: 
db.select sql="SELECT COUNT(*)              AS n_days, \
                      MIN(datetime)         AS first_date, \
                      MAX(datetime)         AS last_date, \
                      ROUND(MIN(value), 0)  AS min_cfs, \
                      ROUND(AVG(value), 0)  AS mean_cfs, \
                      ROUND(MAX(value), 0)  AS max_cfs \
               FROM mississippi_stpaul_timeseries \
               WHERE value IS NOT NULL"

5. Rating curve

Stage-discharge relationship showing the shift tapering from 0.22 ft at low stage to zero above ~8.5 ft (the shift compensates for recent channel change at low flows): 
db.select sql="SELECT site_no, \
                      ROUND(shift_ft, 2)      AS shift_ft, \
                      ROUND(stage_ft, 1)      AS stage_ft, \
                      ROUND(discharge_cfs, 0) AS discharge_cfs \
               FROM mississippi_stpaul_ratings \
               WHERE stage_ft IN (4.0, 5.0, 6.0, 7.0, 8.0) \
               ORDER BY stage_ft"
